# Skor Maciok

Pencatat skor poin untuk maciok / mahjong (YDSP Bandung rule, varian Kim-joker).
PWA offline untuk meja — skor dihitung otomatis. Tanpa akun, tanpa server, tanpa iklan.

## Apa yang aplikasi ini lakukan

Mencatat hasil tiap babak **dalam poin** dan menghitung pembagiannya antar pemain di meja.
Poin di sini adalah satuan permainan, bukan nilai uang dan bukan klaim atas apa pun.

## Apa yang tidak ada di dalamnya

- Tidak ada uang, taruhan, atau transaksi dalam bentuk apa pun.
- Tidak ada konversi poin ke mata uang apa pun, dan tidak ada tempat untuk mengisi nominal.
- Tidak ada akun, tidak ada server, tidak ada data yang dikirim ke mana pun. Seluruh catatan
  tersimpan di perangkat pemakainya sendiri.

## Perjudian

Perjudian dilarang oleh peraturan perundang-undangan yang berlaku di Indonesia. Aplikasi ini
tidak memungkinkan, tidak memfasilitasi, dan tidak menganjurkan perjudian dalam bentuk apa pun.
Aplikasi ini adalah alat bantu pencatatan skor, dan tidak lebih dari itu.

## Siapa yang membuatnya

Alat bantu pribadi dan non-komersial, dibuat untuk meja permainan penulisnya sendiri.
